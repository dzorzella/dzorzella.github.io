Port Scanning con Bash: uno script leggero per la diagnostica di rete

Quando si lavora con le reti, a volte serve un modo rapido per verificare se un range di porte è aperto su un dato host. Strumenti come nmap sono potenti e ricchi di funzionalità, ma possono essere eccessivi per compiti semplici o non disponibili in ambienti minimal. Ecco dove uno script Bash leggero come questo diventa utile.

Il codice

#!/bin/bash

host=${1:?"missing arg 1 for host"}
port=${2:?"missing arg 2 for port. Accepted values: [port] | [start-end]"}

if [[ $port =~ ([0-9]+)-([0-9]+) ]]; then
  start=${BASH_REMATCH[1]}
  end=${BASH_REMATCH[2]}
else
  start=$port
  end=$port
fi

log_message() {
  echo "`date \"+%Y-%m-%d %H:%M:%S\"` $1" | tee -a log
}

for p in $(seq $start $end);
do
    if timeout 1 bash -c "</dev/tcp/$host/$p" 2>/dev/null; then
      log_message "Port $p is open on $host"
    else
      log_message "Port $p is closed on $host"
    fi
done

Cosa fa

Questo script esegue un port scan TCP di base su un dato host e range di porte. Verifica ogni porta nel range per vedere se è aperta e registra il risultato con un timestamp.

Funzionalità chiave

  • Validazione degli argomenti — Assicura che host e range di porte siano forniti
  • Regex Matching — Estrae le porte di start e end da un range come 20-25
  • Verifica TCP — Usa il pseudo-device /dev/tcp di Bash per tentare la connessione
  • Gestione del timeout — Previene blocchi su porte non responsive
  • Logging — Output dei risultati su console e file di log con timestamp

Uso di esempio

./main.sh localhost 8000-8010

Perché l'ho scritto

Sebbene non sia robusto o stealth come strumenti dedicati come nmap, ho creato questo script come modo leggero e senza dipendenze per verificare la disponibilità delle porte durante la diagnostica di rete interna. È un ottimo esempio di quanto Bash possa essere potente per compiti rapidi di automazione.
