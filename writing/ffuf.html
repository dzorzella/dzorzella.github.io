Cos'è Ffuf

Ffuf (Fuzz Faster U Fool) è un web fuzzer veloce e flessibile scritto in Go. È principalmente utilizzato per scoprire risorse nascoste sui server web, come directory, file e virtual host.

Nota: nelle wordlist si notano spesso commenti di copyright all'inizio, che possono essere considerati parte della wordlist e creare clutter nei risultati. Usare il flag -ic in ffuf per escludere queste righe.

Nota: per filtrare i risultati per dimensione della risposta in Ffuf, usare l'opzione -fs (filter size). Questo permette di escludere risposte che corrispondono a una dimensione specifica.

Fuzzing dei subdomini pubblici

Questa tecnica permette di identificare subdomini pubblicamente accessibili associati a un dominio principale. Usando una wordlist di nomi di subdomini comuni, ffuf effettua richieste DNS per ogni voce, sostituendo dinamicamente il placeholder FUZZ. Utile per scoprire endpoint nascosti, ambienti di test, panel di amministrazione o servizi non documentati. 

ffuf -w /opt/useful/seclists/Discovery/DNS/subdomains-top1million-5000.txt:FUZZ -u http://FUZZ.$DOMAIN$:$PORT

Enumerazione dei Virtual Host

Questa tecnica sfrutta la funzionalità di virtual hosting dei server web per identificare virtual host configurati ma non documentati. ffuf invia richieste HTTP modificando l'header Host con valori da una wordlist, cercando risposte diverse che indicano virtual host attivi. Particolarmente utile in ambienti dove più siti condividono lo stesso IP. 

ffuf -u http://$DOMAIN:$PORT -H "Host: FUZZ.$DOMAIN" -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt

Page Fuzzing

Il page fuzzing è una tecnica core di web reconnaissance per scoprire risorse nascoste o non linked su un server web. Testando sistematicamente diversi path e nomi di file, questo metodo aiuta a scoprire directory, script e file non direttamente accessibili dalla navigazione del sito.

Extension Fuzzing

Questa tecnica si concentra sul scoprire file nascosti o non elencati fuzzando le estensioni comuni. Appendendo valori da una wordlist a un path noto, ffuf tenta di identificare file accessibili come backup, codice sorgente o file di configurazione. 

ffuf -w /usr/share/seclists/Discovery/Web-Content/web-extensions.txt:FUZZ -u http://$DOMAIN:$PORT/indexFUZZ

Recursive Page Fuzzing

Il recursive page fuzzing mira a enumerare path e directory accessibili su un server web. Usando una wordlist di nomi comuni di directory e file, ffuf esplora ricorsivamente il target, eventualmente appendendo estensioni come .php o .phps. 

ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ -u http://$DOMAIN:$PORT/FUZZ -ic -recursion -recursion-depth 3 -e ".php,.phps" -v -fs xxx

Directory Fuzzing

Il directory fuzzing è una tecnica per scoprire directory nascoste o non elencate su un server web. Inviando richieste HTTP con nomi di directory comuni da una wordlist, aiuta a identificare aree del sito non linkate o visibili attraverso l'interfaccia utente. 

ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt -u http://$DOMAIN:$PORT/FUZZ -ic -recursion -recursion-depth 3 -v

Parametri aggiuntivi

Flag Descrizione
-HAggiungi headers (es. -H "Cookie: sessionid=12345")
-XMetodo HTTP (GET, POST, ecc.)
-dDati POST (es. -d "username=test&password=FUZZ")
-tNumero di thread concorrenti
-oOutput su file in vari formati (csv, json, html)
-mcMatch per status code HTTP
-fsFilter per dimensione risposta
-recursion -recursion-depth xFuzzing ricorsivo

Parameter Fuzzing

Il parameter fuzzing è una tecnica per scoprire parametri nascosti o non documentati che un'applicazione web può accettare. Questi parametri possono influenzare il comportamento dell'applicazione, rivelare dati sensibili o esporre vulnerabilità potenziali.

GET Parameter Fuzzing

Questo metodo mira ai parametri della query string nelle URL. ffuf sostituisce il placeholder FUZZ con nomi di parametri potenziali da una wordlist. 

ffuf -w /opt/useful/seclists/Discovery/Web-Content/burp-parameter-names.txt:FUZZ -u http://$DOMAIN:$PORT/?FUZZ=key -fs xxx

POST Parameter Fuzzing

Simile al GET fuzzing, questa tecnica si concentra sulle richieste POST. Iniettando nomi di parametri nel body della richiesta, ffuf può scoprire logica backend o campi form non esposti nel frontend. 

ffuf -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt:FUZZ -u http://$DOMAIN:$PORT/admin.php -X POST -d "FUZZ=key" -H "Content-Type: application/x-www-form-urlencoded" -fs xxx

Value Fuzzing

Il value fuzzing testa come un parametro noto (es. id) si comporta con valori diversi. Utile per identificare vulnerabilità IDOR (Insecure Direct Object Reference), percorsi di privilege escalation o problemi di input validation. 

ffuf -w ids.txt:FUZZ -u http://$DOMAIN:$PORT/admin.php -X POST -H 'Content-type: application/x-www-form-urlencoded' -d 'id=FUZZ' -fs xxx
